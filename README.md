# Automatic License Plate Recognition (ALPR) System

This project implements an automated system for recognizing Polish vehicle license plates. It utilizes **YOLOv8** for license plate detection and **EasyOCR** for character recognition.

The system achieves a high accuracy rate (**~89%**) by employing a custom **"Lazy Cascade"** image processing logic, which balances performance and precision by applying advanced preprocessing only when necessary.

```text
│   ├── 1_preapare_data.py      # Data preparation script (XML -> YOLO conversion, train/val split)
│   ├── 2_train.py              # Script to start training the YOLO model
│   ├── 3_reasume.py            # Script to resume training (in case of interruption)
│   ├── 4_evaluate_debug.py     # Evaluation with debugging (saves intermediate processing images)
│   ├── 5_evaluate.py           # Main evaluation script (fast, calculates accuracy and final score)

```

### ❗ Important Data Setup Notes:

1. **`data/` Folder**: You must create this manually. Place your `annotations.xml` (ground truth for accuracy testing) inside `data/annotations/` and your raw images inside `data/images/`.
2. **`datasets/` Folder**: This folder is automatically generated when you run `1_preapare_data.py`. Do not create it manually.
3. **`src/debug/` Folder**: This folder is automatically generated when running `4_evaluate_debug.py`.

## ⚙️ Core Logic: "Lazy Cascade"

The system uses a hybrid approach to optimize both speed and accuracy:

1. **Detection**: YOLOv8 locates the license plate bounding box.
2. **Fast Pass**: The crop is converted to grayscale and passed to EasyOCR immediately.
3. **Validation**: The result is checked against a Regex pattern for Polish license plates (e.g., 2-3 letters followed by 4-5 alphanumeric characters). If it matches, the process stops here (saving time).
4. **Heavy Pass (Fallback)**: If the result is weak or doesn't match the pattern, the system applies advanced preprocessing (Upscaling to 96px height + CLAHE + Sharpening) and retries OCR.
5. **Heuristics**: Post-processing rules fix common OCR errors (e.g., `S` vs `5`, `Z` vs `7`, removing "phantom 1s" from plate borders).

## ▶️ Usage Guide

### 1. Data Preparation

Before training or evaluation, you must convert the raw XML annotations into YOLO format and split the data into training and validation sets.

**Run this once:**

```bash
cd src
python 1_preapare_data.py

```

*Effect:* Creates the `datasets/` folder structure required by YOLO.

### 2. Training (Optional)

If you need to retrain the YOLO model on new data:

```bash
cd src
python 2_train.py

```

### 3. Evaluation (Testing Accuracy)

This is the main script to verify the system's performance. It processes the validation dataset and compares results against `annotations.xml`.

**For clean, fast results (Final Grade Mode):**

```bash
cd src
python 5_evaluate.py

```

**For debugging (saves processed images to `src/debug/`):**

```bash
cd src
python 4_evaluate_debug.py

```

## 📊 Performance

* **Accuracy:** ~89% on the validation set.
* **Processing Time:** ~45-50 seconds per 100 images.
* **Method:** Cascade Logic (Fast OCR -> Heavy OCR fallback).
